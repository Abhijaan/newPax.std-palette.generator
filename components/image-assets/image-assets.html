Android SplashScreen API reference

Without icon background 288 × 288 dp Keep artwork inside a 192 dp diameter circle.
With icon background 240 × 240 dp Keep artwork inside a 160 dp diameter circle.
Branded image 200 × 80 dp A separate option for brand artwork, not the app icon.

These are Android's documented dp specifications, not a guarantee that an arbitrary SVG will be a valid Android VectorDrawable. For Android implementation, export/use a compatible vector drawable or convert and test the asset in your project. Official Android splash screen guidelines ↗
